## 🚀 Cómo ejecutar el proyecto

#### Clonar el repositorio:

```http
   git clone https://github.com/tu-usuario/disney-app.git
   cd disney-app

```
#### Instalar dependencias del servidor:

```http
    cd server
    npm i
```

#### Instalar dependencias del cliente

```http
    cd ../cliente
    npm i
```
#### Configurar variables de entorno:

- Crea un archivo .env en la carpeta server y configura las variables necesarias (como la conexión a la base de datos y la clave secreta de JWT).

#### Ejecutar el servidor
```http
    cd server
    npm run dev
```

#### Ejecutar el cliente
```http
    cd ../cliente
    npm start
```
#### ¡Explora la app! 🎉
- Abre tu navegador y visita http://localhost:3000 para ver la aplicación en acción.
